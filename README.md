# Calculadora de IMC

  Este foi um exercício que tinha como objetivo:
- Copiar o design do site
- Realizar o calculo imc
- Fazer com que o resultado fosse mostrado ao usuário na tela
- Mostrar na tabela o nível de obesidade ou magreza
- Limpar os dados da consulta e indicar caso algum campo não fosse preenchido corretamente.

Linguagens Utilizadas:
-  HTML
-  CSS
-  JAVASCRIPT  

Observação:
  Aqui não ouve preocupação com responsividade, foi apenas estudo do HTML e CSS
